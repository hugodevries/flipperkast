# Tijmens Ruimte-Flipperkast 🚀

Een flipperkast in de ruimte, gemaakt voor Tijmen. Open `index.html` in een browser, of ga naar de speellink van deze repository (GitHub Pages).

- Linker en rechter gele knop (of de linker- en rechterkant van het scherm): de flippers
- Op de computer: `Z` en `M`
- 1 punt voor elke planeet, de ruimtepoort bovenaan en elke lichtbrug
